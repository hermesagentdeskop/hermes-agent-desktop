# Hermes Agent Desktop

**Hermes Agent Desktop** is the Nous Research agent on Windows, Mac and Linux. Local Ollama or a cloud API. Tools, skills, schedules, gateway, persona.

4. Open Chat.

## FAQ

**What is it?**
A tool-calling agent from Nous. Not a chat skin.

**vs Claude / Gemini desktops?**
Those are chat windows. This one runs tools.

**Tools fail on Windows?**
`PATH` empty for the terminal tool.
